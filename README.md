# Pixel Loom

无需后端、打开即可使用的像素动画编辑器。直接用浏览器打开 `index.html`（或任意静态服务器托管）即可。

## 功能

- **多图层**：新增、移除、上移/下移排序、显隐切换、锁定（锁定/隐藏后不可绘制）、双击重命名
- **帧动画**：逐帧时长（20–5000ms，可一键应用到全部帧）、新增 / 复制 / 删除 / 前移后移、循环播放（可关闭）
- **绘制工具**：画笔（拖动自动补间连线）、橡皮、油漆桶填充、取色器（或画布右键取色）、16 色调色板 + 自定义颜色
- **矩形选区**：拖动框选；选区内拖动移动内容；复制 / 剪切 / 粘贴（可跨帧、跨图层）；Enter 贴下、Esc 取消；贴下只写入不透明像素；选区与浮动内容纳入撤销历史和本地保存
- **撤销 / 重做**：快照式历史（100 步），覆盖所有编辑操作——绘制、填充、选区变化、帧/图层增删排序、显隐锁定、时长修改、新建项目
- **持久化**：编辑后自动保存到 `localStorage`，刷新 / 关闭重开自动恢复；Ctrl+S 手动保存
- **导出**：当前帧 PNG（4x）、精灵图 PNG（全帧横向排列）、动画 GIF（内置 GIF89a + LZW 编码器，逐帧延时、NETSCAPE 循环扩展、透明通道）
- **辅助**：缩放、像素网格、洋葱皮（前一帧残影）
- **键盘与窄屏**：完整快捷键（按 `?` 查看）；响应式布局，窄屏单列、触屏可画

## 快捷键

| 键 | 功能 |
| --- | --- |
| `B` / `E` / `G` / `I` | 画笔 / 橡皮 / 填充 / 取色 |
| `M` | 选区（拖动框选，选区内拖动移动） |
| `Ctrl/⌘ C` `X` `V` | 复制 / 剪切 / 粘贴选区 |
| `Enter` / `Esc` | 贴下浮动内容 / 取消选区 |
| `Ctrl/⌘ Z` · `Ctrl/⌘ ⇧ Z` | 撤销 · 重做 |
| `Ctrl/⌘ S` | 保存 |
| `空格` | 播放 / 暂停 |
| `←` `→` / `↑` `↓` | 切换帧 / 切换图层 |
| `D` / `Delete` | 复制帧 / 删除帧 |
| `[` `]` | 当前帧前移 / 后移 |

## 验证

两套测试均在项目根目录运行，不依赖固定工作区路径。

**逻辑测试**（零依赖，直接运行）：

```bash
node test-core.js   # 86 项：模型、选区、撤销重做、序列化往返、GIF 字节级解析 + LZW 解码回验
```

**浏览器冒烟测试**（64 项：绘制、选区、帧/图层操作、播放、保存刷新恢复、导出、窄屏触摸）：

```bash
npm install                      # 安装 playwright（见 package.json）
npx playwright install chromium  # 下载浏览器；缺系统库时用 --with-deps（需 root）
node test-browser.js             # 内置静态服务器，无需手动起服务
```

浏览器测试启动前会先做依赖预检：浏览器二进制缺失或系统运行库不足时，直接说明缺失项并给出可执行的准备命令（不会报出晦涩的 "browser process closed"，也不会跳过用例）；预检通过才执行全部 64 项用例。
